# 기획 프로그레스

## 1. 기획 기준

기획의 핵심 질문은 “무엇을 더 만들 수 있는가”가 아니라 “어떤 고객이 어떤 결정을 더 정확하고
빠르게 내리게 되는가”다. 초기 고객은 원자재를 수입하고 완제품을 수출하는 중소·중견
제조기업이며, 첫 번째 효용은 결제일 기반 자금 공백과 환노출을 발견하고 상담 준비를 끝내는 것이다.

차별화 문장은 다음으로 고정한다.

> TradeFlow는 답만 하지 않는다. 무엇이 답을 바꾸는지 보여주고, 그 변화 과정을 상담 가능한
> 근거 패킷으로 남긴다.

## 3. 현재 제공 가치와 제외 가치

### 제공하는 가치

- 지급·수취 일정으로 최대 자금 공백과 환노출을 계산한다.
- 결과를 바꾸는 입력을 우선 질문하고 전후 변화를 보여준다.
- 금융·보증 후보를 근거, 누락 조건과 검토 필요 상태로 제시한다.
- 상담 자료와 수동 전달 이후의 진행 이력을 보존한다.

### 아직 주장하지 않는 가치

- KB 상품의 실제 취급 가능 여부, 한도, 금리 또는 승인 가능성
- K-SURE·외국환 규칙의 운영 확정 판정
- L/C, D/P, D/A, O/A, Payment Usance 전 과정 지원
- 은행·보증기관·보험기관 시스템 자동 접수

## 4. 파일럿 성공 기준

실제 파일럿은 자동화 benchmark와 분리해 다음을 측정한다.

| 지표 | 측정 방법 | 초기 합격 기준 |
|---|---|---:|
| 고객 과업 완료율 | 거래 입력부터 상담자료 준비까지 관찰 | 80% 이상 |
| 자금 공백 이해도 | 결과 설명 후 금액·시점 재진술 | 80% 이상 |
| 결과 변경 이해도 | 어떤 입력이 판정을 바꿨는지 설명 | 70% 이상 |
| 상담자료 유용성 | RM 5점 척도 평가 | 평균 4.0 이상 |
| 준비시간 절감 | 기존 방식 대비 소요시간 비교 | 중앙값 30% 이상 절감 |
| 과신 방지 | 미확인 상태를 승인으로 오인한 비율 | 0% 목표 |

합격 기준은 첫 pilot cohort 전에 동결하고 결과를 본 뒤 소급 변경하지 않는다.

## 5. 다음 기획 결정

1. 파일럿 cohort를 `수입 원자재 + 수출 완제품` 기업으로 제한할지 확정한다.
2. 상담 필수 정보 중 사용자 직접 입력과 외부 provider 수집 범위를 나눈다.
3. 네 미지원 capability의 우선순위를 인터뷰 결과로 결정한다.
4. 도메인 전문가 승인 일정을 제품 출시 일정과 별도 critical path로 관리한다.
