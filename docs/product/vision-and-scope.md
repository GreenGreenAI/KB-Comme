# 제품 비전과 범위

KB Comme는 중소·중견기업과 은행 RM이 수출입 거래의 현금흐름, 환노출, 금융지원
가능성과 필요한 근거를 하나의 거래 단위에서 검토하도록 돕는 의사결정 지원 기반이다.

## 현재 목표

- USD T/T 연결 거래를 대표 사례로 고정한다.
- 거래 입력에서 현금흐름과 환노출을 계산한다.
- 출처가 확인된 규칙만 금융지원 후보 판정에 사용한다.
- 결과마다 사용한 입력, 계산식, 출처와 불확실성을 반환한다.
- 사람의 최종 검토 없이 불확실한 정보를 확정 판정으로 승격하지 않는다.

## 현재 제외 범위

- 실제 자금 집행이나 대출 승인
- 고객 동의 없는 외부 시스템 변경
- 출처 없는 규정의 자동 적용
- 모든 통화, 결제방식과 상품의 동시 지원

상세 문제 정의와 전체 범위는
[통합 제품·아키텍처 기획서](product-architecture-plan.md)를 기준으로 한다.
