# 제품 로드맵

| 단계 | 목표 | 완료 기준 |
|---|---|---|
| Phase 0 | 업무·데이터 정의 | 대표 거래, 용어, 출처와 기대 결과 합의 |
| Phase 1 | 거래·계산 기반 | 현금흐름·환노출 계산과 회귀 테스트 |
| Phase 2 | 금융지원 탐색 | 출처 기반 후보 판정과 근거 패킷 |
| Phase 3 | 실행·검토 | 기업·RM 검토 흐름과 감사 기록 |
| Phase 4 | 문서·신용장 | 문서 추출과 결제방식 확장 |
| Phase 5 | 외부 연동 | 승인된 시스템별 안전한 통합 |

단계의 범위와 우선순위를 바꾸는 PR은 변경 이유, 성공 지표와 영향을 함께 기록한다.
상세 백로그는 이 문서가 아니라 이슈 트래커에서 관리한다.
