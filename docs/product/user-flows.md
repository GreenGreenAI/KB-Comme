# 사용자 흐름

## 기업 사용자

1. 거래와 결제 조건을 등록한다.
2. 관련 문서와 확인 가능한 근거를 연결한다.
3. 현금흐름, 환노출과 자금 공백을 확인한다.
4. 조건에 맞는 금융지원 후보와 미확인 사항을 검토한다.
5. 필요하면 은행 RM에게 근거 패킷과 함께 검토를 요청한다.

## 은행 RM

1. 기업이 제출한 거래와 근거를 확인한다.
2. 계산 입력, 규칙 버전과 판정 사유를 검토한다.
3. 추가 자료 또는 수정된 조건을 요청한다.
4. 검토 결과를 기록하되 최종 금융기관 절차와 분리한다.

구체적인 화면 정보구조와 예외 흐름은
[통합 제품·아키텍처 기획서](product-architecture-plan.md)에서 관리한다.
