# 보안과 감사

## 기본 원칙

- 최소 권한과 역할 기반 접근 제어를 적용한다.
- 고객 데이터와 비밀값을 저장소에 커밋하지 않는다.
- 판정과 계산에 사용된 입력, 버전, 출처와 검토자를 추적한다.
- 외부 연동은 명시적인 권한과 실패 시 안전한 기본 동작을 가진다.
- 보존 기간과 삭제 정책은 데이터 종류별로 정의한다.

구현 전 인증, 권한, 암호화, 감사 로그, 개인정보와 사고 대응 요구사항을 위협 모델과
함께 구체화해야 한다.
