# 문서 보관 정책

더 이상 현재 기준이 아니지만 이력 보존 가치가 있는 문서를 저장한다.

- 문서를 옮기기 전에 상태를 `deprecated`로 바꾼다.
- 문서 상단에 대체 문서와 보관 이유를 기록한다.
- 외부 링크가 필요하지 않으면 문서 포털의 기본 읽기 순서에서 제거한다.
- 법적·보안상 삭제가 필요한 데이터는 archive에 보관하지 않는다.

승인된 ADR은 이 디렉터리로 옮기지 않고 `adr/`에서 상태만 변경한다.
